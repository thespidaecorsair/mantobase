# mantobase
A simple website highlighting the species of Australian mantids, providing a key to identify them alongside mantid information.

This website provides a polytomous key to identify mantids in Australia, alongside links to further information. It is meant to be able to provide otherwise hard to understand/find information in a more accesible layout, with concepts explained for less experienced citizen scientists on the topic.

You can access this through the link: https://thespidaecorsair.github.io/mantobase/

The key sorts through different features of different mantids, especially with the kind of variety that Australia provides.
It also explains concepts and helps make note of things people should be aware of for future mantid identification.

AI has not been used, apart from inline suggestions occasionally on VSCode (12%).
